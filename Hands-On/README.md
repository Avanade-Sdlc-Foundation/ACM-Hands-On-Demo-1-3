# プロンプトファイルとドキュメント生成ハンズオン

GitHub Copilotのカスタム指示とプロンプトファイルを使用して、Java Spring Bootプロジェクトの高品質なドキュメントを生成するプロセスを学習します。カスタム指示の作成、適用、比較方法、およびアーキテクチャドキュメント用のブループリントプロンプトの活用方法を習得します。

## ラボの概要

> [!IMPORTANT]
> このラボの技術や生成AIツールは確率論的であるため、スクリーンショットや
> コードスニペットと実際の体験に違いが生じる可能性があります。

このラボでは、GitHub CopilotのAgent機能とブループリントプロンプトを活用して、Spring Boot PetClinicプロジェクトの包括的なドキュメントを自動生成する方法を順を追って説明します。

1. [GitHub Copilot Agentモードでのカスタム指示ファイル作成](./1-agent-instructions.md)

3. [2つの指示ファイルの比較と分析](./3-comparison.md)
4. [カスタムプロンプトを使用したアーキテクチャドキュメントの生成](./4-architecture-docs.md)

## シナリオ

新しく参画したSpring Boot PetClinicプロジェクトのチームメンバーとして、以下の課題に直面しています：

- プロジェクトのアーキテクチャ設計書が古い
- コーディング標準やベストプラクティスが明文化されていない
- 技術的負債の把握と改善計画が存在しない
- 新規メンバーのオンボーディングに時間がかかる

このハンズオンを通じて、GitHub Copilotの最新機能を活用して、これらの課題を効率的に解決する方法を学習します。特に、Agent機能とブループリントプロンプトの違いと効果的な使い分けについて実践的に理解します。

## 学習目標

このラボ完了後、以下のスキルを習得できます：

- GitHub Copilot Agentモードの基本的な使用方法
- ブループリントプロンプトを活用したより詳細な分析
- プロジェクト固有のカスタム指示ファイル作成
- 高品質なアーキテクチャドキュメントの自動生成
- 技術的負債の体系的な分析と改善計画策定
